# HapticImproveManager — 多语言(i18n)支持 设计文档

> 日期:2026-10-11 · 状态:待评审
> 前置决策(头脑风暴已批准):语言切换**重启后生效**;翻译存取用**轻量字典式 tr()**(非 QTranslator / JSON 资源文件)

## 1. 目标

给 GUI 加中/英双语支持:

1. 所有用户可见界面文字跟随语言设置(约 120 串,含 backend 经 UI 显示的校验/反作弊消息)
2. 设置页提供语言下拉:跟随系统 / 中文 / English
3. 语言偏好持久化于 `gui_config.json`,重启应用后生效

**不做**:日志文件内容、注入器子进程输出(诊断数据,保持原文);代码注释/docstring(保持项目现有中文风格);运行时实时切换(已明确选择重启生效)。

## 2. 机制:根级 `i18n.py` 字典目录

单文件目录,每键中英并排——对照可见、完整性可单测:

```python
# i18n.py(纯 Python,无 Qt 依赖)
_MESSAGES: dict[str, dict[str, str]] = {
    "settings.title": {"zh": "设置", "en": "Settings"},
    "unit.frames":    {"zh": "{n} 帧", "en": "{n} frames"},
    ...
}

_LANG = "zh"  # 模块默认值;仅启动时 set_language 覆盖一次

def tr(key: str, **params) -> str:
    """查当前语言;插值用 {name} 占位 + tr(key, name=...)。
    回退链:当前语言缺失 → zh → 返回 key 本身(任何情况下不抛异常)。"""

def set_language(lang: str) -> None: ...
def current_language() -> str: ...
def resolve_language(setting: str, system_locale: str) -> str:
    """setting ∈ System/zh/en;System → system_locale 以 'zh' 开头则 zh 否则 en。
    未知 setting(手改 json)按 System 处理。
    system_locale 由调用方(QLocale)注入,保持本模块无 Qt 可单测。"""
```

**为什么放根级**:`backend/config.py` 的 `validate()` 校验消息与
`backend/anticheat.py` 的反作弊显示名(腾讯 ACE 等)经 UI 显示,同样需要
tr()。根级模块可被 ui 与 backend 双向导入,不破坏 `ui → backend` 单向依赖。

**键命名**按页面分层:`app.title`、`nav.*`、`settings.*`、`games.*`、
`detail.*`、`config.*`、`mode.<Mode>.{title,brief,detail}`、`wizard.*`、
`diag.*`、`validate.*`、`ac.*`、`common.{on,off}`、`unit.*`。

## 3. 启动时序与模块级铁律

```
app.py → create_main_window():
    1. i18n.set_language(resolve_language(cfg.language.value,
                                          QLocale.system().name()))
    2. 之后才开始构建任何页面
```

**铁律:`tr()` 只在运行时调用,禁止模块级调用。** 模块级常量在 import 时
求值,会冻结在当时的 `_LANG`(默认 zh),之后 set_language 对其无效。
现有两个模块级文案常量须移入 `__init__`:

- `ui/settings_page.py` 的 `_THEME_LABELS`
- `ui/add_game_dialog.py` 的 `_STEPS`

`AppConfig` 新增:

```python
language = OptionsConfigItem(
    "MainWindow", "Language", "System",
    OptionsValidator(["System", "zh", "en"]))
```

**重启生效语义**:运行中切换只写盘、不重设 `_LANG`,避免半中半英的中间
状态;设置页切换后 InfoBar 提示"重启应用后生效"。

## 4. 设置页 UI

主题下拉上方加"语言"下拉,标签为 `[tr("settings.lang_system"), "中文",
"English"]` —— 第一项随当前语言翻译,后两项用各语言自称(惯例,保证用户
在任何语言界面下都能认出自己的语言)。

## 5. 调用点改造范围

| 文件 | 内容 |
|---|---|
| `ui/settings_page.py` | 标题/主题/Mica/日志目录/同步对话框/InfoBar;新增语言下拉 |
| `ui/main_window.py` | 窗口标题(`app.title`)、3 个导航项 |
| `ui/games_page.py` | 搜索占位/添加按钮/空状态/列表项 hint(`unit.frames`) |
| `ui/game_detail.py` | 按钮/状态卡/状态徽章文案/IFEO/移除确认/提示 |
| `ui/config_card.py` | 表单标签/说明/保存流程/校验对话框/StateToolTip |
| `ui/config_model.py` | `MODE_INFO` 文案移入 i18n 目录(`mode.*` 键);本文件回归纯映射,不再持有文案 |
| `ui/add_game_dialog.py` | 四步向导全部文案/步骤标签/反作弊确认 |
| `ui/diagnostics_page.py` | 标题/最近注入/按钮/日志说明 |
| `backend/config.py` | `validate()` 4 条 problems 走 tr |
| `backend/anticheat.py` | 反作弊显示名(腾讯 ACE 等)走 tr |

细节:

- 窗口标题:`"Haptic 低延迟管理器"` / `"Haptic Low-Latency Manager"`
- 列表项 `f"{mode_hint} · {buffer_hint} 帧"`:mode_hint 为注册表中的模式键
  (Normal/…),显示经 `{m: tr(f"mode.{m}.title") for m in MODES}.get(hint,
  hint)` —— 已知模式译出,意外值(手改 yaml)原样显示而不露出消息键
- 诊断页 Pivot 选项卡文字是日志文件名(`injector_debug`/`wasapi_relink`),
  属专有名词,不翻
- `test_smoke.py` 现断言 `windowTitle() == "Haptic 低延迟管理器"`,随 i18n
  引入需在 fixture 显式 `set_language("zh")` pin 住(默认 System 会随测试机
  语言环境漂移)

## 6. 测试

新增 `tests/test_i18n.py`:

1. **目录完整性**:`_MESSAGES` 每个键都有非空 zh 与 en
2. **插值一致性**:同一键 zh/en 的 `{...}` 占位符集合相同(防翻译漏参数
   导致运行时 KeyError)
3. **resolve_language 映射**:表驱动(System+zh_CN/zh_TW/en_US/…,显式
   zh/en,未知 setting 回退)
4. **回退行为**:未收录键返回 key 本身;某语言缺失回退 zh

`test_smoke.py`:fixture 加 `i18n.set_language("zh")`,标题断言改走 tr 或
保持中文常量(与 pin 后行为一致)。

手动验证:中英文各启动一遍,过一遍四个页面核对文案。
